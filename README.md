# 🔐 Password Vault

A simple password manager made with HTML, CSS, and JavaScript.

I built this project to practice JavaScript, DOM manipulation, localStorage, and frontend development.

## Features

* Add and save passwords
* Generate random passwords
* Check password strength
* Show/hide passwords
* Copy passwords
* Edit and delete entries
* Search saved accounts
* Light/dark mode
* Responsive design

## Tech Used

* HTML
* CSS
* JavaScript
* LocalStorage

## Run Locally

1. Clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` with Live Server.
4. Start adding your passwords.

